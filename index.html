Objetivos de aprendizaje


  • Acceder a elementos usando tablero[fila][columna].
  • Recorrer filas y columnas con while y contadores.
  • Comparar elementos con if y operadores lógicos.
  • Detectar victoria, empate y fin de partida.
  • Validar jugadas y contar casillas libres con while.

Editor de lógica
Completa los cinco retos


La interfaz y los turnos ya están programados. Tu trabajo es completar únicamente el cuerpo de las funciones. Debes usar la matriz tablero y bucles while. Las soluciones no están incluidas. Al aprobar todas las pruebas podrás generar tu certificado PNG.


Reto 1 · Detectar una fila ganadora Básico
Devuelve true si el jugador tiene tres símbolos iguales en alguna fila. En caso contrario, devuelve false.


Reto 2 · Detectar columnas y diagonales Intermedio
Devuelve true si el jugador tiene tres símbolos en alguna columna o diagonal. No necesitas revisar las filas aquí. Utiliza un while para las columnas y condiciones if para las diagonales.


Reto 3 · Detectar un empate Intermedio
Devuelve true solamente si no queda ninguna celda vacía. El juego comprobará antes si alguien ganó.


Reto 4 · Validar una jugada Intermedio
Devuelve true si la fila y columna están dentro del tablero (de 0 a 2) y la celda está vacía. En cualquier otro caso, devuelve false. Usa if. No necesitas un bucle en este reto.


Reto 5 · Contar casillas vacías Intermedio
Recorre toda la matriz usando dos bucles while y devuelve la cantidad de casillas vacías (un número de 0 a 9).
